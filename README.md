# איקס עיגול · זירת הקרח

משחק איקס-עיגול בדפדפן, עם עיצוב קרח ולוח 3×3. אפשר לשחק נגד המחשב או בשני שחקנים על אותו מסך.

## הרצה

אין צורך בהתקנה. פתחו את `index.html` בדפדפן.

## איך משחקים

- **נגד מחשב** — אתם עיגול (○), המחשב איקס (✕). המחשב בוחר מהלך עם minimax.
- **שני שחקנים** — עיגול מתחיל, ואז מתחלפים.
- **סיבוב חדש** — מאפס את הלוח ושומר את הניקוד.
- **מהלך אחורה** — מבטל את המהלך האחרון (במצב AI מבטל גם את מהלך המחשב).
- החלפת מצב משחק מאפסת גם את הניקוד.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | מבנה העמוד והלוח |
| `styles.css` | עיצוב זירת הקרח |
| `game.js` | לוגיקת המשחק, ניקוד ו-AI |
