# איקס עיגול · זירת הקרח

משחק איקס-עיגול בדפדפן, עם עיצוב קרח ו-RTL בעברית. אפשר לשחק נגד מחשב (Minimax) או שני שחקנים על אותו מכשיר.

## הרצה

אין תלויות. פותחים את `index.html` בדפדפן, או מגישים את התיקייה כאתר סטטי.

```bash
# לדוגמה עם Python
python -m http.server 8000
```

ואז נכנסים ל־[http://localhost:8000](http://localhost:8000).

## מה יש במשחק

- **נגד מחשב** — אתה עיגול (○), המחשב איקס (✕) עם מהלך אופטימלי
- **שני שחקנים** — תורות מתחלפים על אותו לוח
- ניקוד מצטבר (עיגול / תיקו / איקס) עד שמחליפים מצב משחק
- קו ניצחון על הלוח
- ביטול מהלך אחרון (במצב AI מבטל גם את מהלך המחשב)
- סיבוב חדש בלי לאפס ניקוד

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | מבנה העמוד, הלוח והפקדים |
| `styles.css` | ערכת קרח, לוח, ניקוד וכפתורים |
| `game.js` | חוקי המשחק, Minimax, undo ואירועים |

## AI

המחשב בוחר מהלך עם Minimax על לוח 3×3. בלוח מלא אין הפתעות: משחק מושלם מסתיים בתיקו אם שני הצדדים לא טועים.
